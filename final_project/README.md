# Финальный проект

## Тема

Генерация видео по текстовому описанию и изображению.

## Реализация

Для проекта использована модель [CogVideo](https://github.com/zai-org/CogVideo/tree/main). Данная модель имеет возможность fine-tuning, однако требования по железу слишком высокие для обучения локально на домашнем пк (минимальные требования видеопамяти 24гб при обучении LoRA).

Используемый стек:

- django
- celery
- redis
